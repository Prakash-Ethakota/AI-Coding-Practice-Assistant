
# AI Coding Practice Assistant

A beginner-friendly Python coding practice app built using Streamlit.

## Features
- Practice beginner Python problems
- View hints for solving problems
- Write Python code in the app
- Learn programming through hands-on practice

## Technologies Used
- Python
- Streamlit

## How to Run Locally

1. Clone this repository.
2. Install the dependencies:

   `python -m pip install -r requirements.txt`

3. Start the application:

   `python -m streamlit run app.py`
